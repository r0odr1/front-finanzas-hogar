# Finanzas Hogar — Frontend

Aplicación personal para la gestión y control de las finanzas del hogar.

Este repositorio contiene el frontend de **Finanzas Hogar**, desarrollado con Ionic, Angular y TypeScript, con soporte previsto para Web, PWA, Android e iOS.

## Objetivo

Centralizar y facilitar la administración financiera del hogar, incluyendo:

- Registro y consulta de movimientos.
- Ingresos mensuales.
- Categorías.
- Presupuestos.
- Reportes financieros.
- Comparativos mensuales.
- Cierres mensuales.
- Alertas financieras.
- Gestión de los miembros del hogar.

## Tecnologías

- Ionic
- Angular
- TypeScript
- Capacitor
- Ionicons

## Backend

El backend se mantiene en un repositorio independiente y está desarrollado con Node.js, Express, TypeScript, Prisma y PostgreSQL.
